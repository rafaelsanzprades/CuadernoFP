# Global Rules
1. **Capitalization in Spanish (Sentence Case):**
   - In Spanish UI headers, navigation titles, and general text, **always** use Sentence case (Solo la primera letra en mayúscula), NEVER Title Case (Todas Las Palabras En Mayúscula).
   - E.g., "Configuración de instrumentos e indicadores" instead of "Configuración de Instrumentos e Indicadores".
