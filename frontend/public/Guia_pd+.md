# APP → PD+ (Detallada JEG): de la programación detallada a dónde se rellena

A continuación, se detalla el índice oficial de la Programación Didáctica según el modelo detallado (JEG, >60 páginas) y se indica **exactamente dónde se debe introducir** esa información en Cuaderno FP. El motor generador de documentos recopilará automáticamente todos estos datos para confeccionar el archivo DOCX final.

---

## 1. Introducción

### 1.1 Identificación
- **Dónde:** `Programación` › `Contexto` → Pestaña `Identificación`

### 1.2 Marco normativo
- **Dónde:** `Programación` › `Normativa` → Pestaña `Legislación`

### 1.3 Contextualización
- **1.3.1 Entorno geográfico y sociocultural**
  - **Dónde:** `Programación` › `Contexto` → Pestaña `Entorno`
- **1.3.2 Entorno socioeconómico y productivo**
  - **Dónde:** `Programación` › `Contexto` → Pestaña `Entorno`
- **1.3.3 Contexto escolar**
  - **Dónde:** `Programación` › `Contexto` → Pestaña `Entorno`
- **1.3.4 Características del alumnado**
  - **Dónde:** `Programación` › `Contexto` → Pestaña `Entorno` (bloque "Contexto escolar", campo "Características del alumnado") y Pestaña `Alumnado` (bloques "Alumnado (ACNEAE)" y "Rasgos característicos del grupo")
- **1.3.5 Infraestructura y recursos educativos**
  - **Dónde:** `Programación` › `Contexto` → Pestaña `Entorno`

## 2. Desarrollo curricular

### 2.1 Duración, ubicación y distribución horaria
- **Dónde:** `Curso` › `Calendario` → Pestaña `Fechas y horario`

### 2.2 Estándares de competencias profesionales (ECP)
- **Dónde:** `Programación` › `Normativa` → Pestaña `ECP INCUAL`

### 2.3 Competencias profesionales, personales y sociales (CPPS)
- **Dónde:** `Programación` › `Catálogo` → Pestaña `Títulos` (Artículo 5 del currículo oficial)

### 2.4 Objetivos generales (OG)
- **Dónde:** `Programación` › `Currículo` → Pestaña `Contribución OG <- RA`

### 2.5 Resultados de aprendizaje (RA) y criterios de evaluación (CE)
- **Dónde:** `Programación` › `Currículo` → Pestaña `Relación RA <- CE`

### 2.6 Contenidos (C)
- **Dónde:** `Programación` › `Currículo` → Pestaña `Relación RA <- CE` (integrado con cada RA)

### 2.7 Relación entre los elementos curriculares
- **Dónde:** `Programación` › `Currículo` → Pestaña `Unidades didácticas` (matriz e informe de relación RA-UD, integrados en la misma pestaña)

### 2.8 Organización temporal: unidades didácticas
- **Dónde:** `Programación` › `Currículo` → Pestaña `Unidades didácticas` (y pestaña `Proyectos y retos` para la secuenciación de tareas)

### 2.9 Formación en empresa (FEOE)
- **Dónde:** `Programación` › `Contexto` → Pestaña `Entorno` (bloque "FEOE")
