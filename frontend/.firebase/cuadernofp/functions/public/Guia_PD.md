# Guía de Referencia: Modelo de Programación TodoFP (v1)

A continuación, se detalla el índice oficial de la Programación Didáctica según el modelo de TodoFP y se indica **exactamente dónde se debe introducir** esa información en la plataforma CuadernoFP. El motor generador de documentos recopilará automáticamente todos estos datos para confeccionar el archivo DOCX final.

---

## 1. Introducción

### 1.1 Identificación
- **Dónde:** `Programación` > `Contexto` → Pestaña `Datos`

### 1.2 Marco normativo
- **Dónde:** `General` > `Documentos` → Pestaña `Normativa`

### 1.3 Contextualización
- **1.3.1 Entorno geográfico y sociocultural**
  - **Dónde:** `Programación` > `Contexto` → Pestaña `Contexto`
- **1.3.2 Entorno socioeconómico y productivo**
  - **Dónde:** `Programación` > `Contexto` → Pestaña `Contexto`
- **1.3.3 Contexto escolar**
  - **Dónde:** `Programación` > `Contexto` → Pestaña `Contexto`
- **1.3.4 Características del alumnado**
  - **Dónde:** `Curso` > `Alumnado` → Pestañas `Listado` y `Contexto del grupo`
- **1.3.5 Infraestructura y recursos educativos**
  - **Dónde:** `Programación` > `Contexto` → Pestaña `Planes`
